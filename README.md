 Pharma Dictionary Chatbot
A Retrieval-Augmented Generation (RAG) chatbot built using:

Streamlit
LangChain
Groq LLM
ChromaDB
HuggingFace Embeddings
PyMuPDF
Features
Ask pharmaceutical questions
Retrieves information from Pharmacy Dictionary PDF
Uses RAG pipeline
Displays source pages
Setup
Install dependencies:

pip install -r requirements.txt
Run locally:

streamlit run app.py
Create:

.streamlit/secrets.toml

GROQ_API_KEY="YOUR_KEY"
Deployment
Push code to GitHub
Login to Streamlit Cloud
Connect your repository
Add GROQ_API_KEY in Streamlit Secrets
